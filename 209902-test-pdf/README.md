## Docker 入門分享
本分享旨在為初學者介紹 Docker 的基本概念與核心指令，讓參與者能快速理解容器化技術的優勢，並掌握建構與管理容器的基礎能力。

### 什麼是容器？
容器是一種輕量級、可攜式、獨立運行的軟體單元。它將應用程式及其所有相依套件（如函式庫、系統工具、程式碼和運行時）打包在一起。這樣的好處是確保應用程式在任何環境中都能夠一致地運行，避免了「在我的機器上可以執行」的問題，極大地簡化了開發、測試和部署流程。

### Image 與 Container
在 Docker 的世界中，理解 Image 和 Container 的區別是至關重要的：
- **Image (映像檔)**：Image 是一個唯讀的模板，包含了運行特定應用程式所需的所有環境、設定和程式碼。它是一個靜態的、不可變的檔案，可以被重複使用來創建多個容器實例。你可以把 Image 想像成一個軟體安裝包或作業系統的快照。
- **Container (容器)**：Container 則是 Image 的一個執行實例。當你從一個 Image 啟動一個 Container 時，實際上是在這個唯讀的 Image 之上添加一個可寫層，形成一個獨立、可運行的環境。每個 Container 都是隔離的，擁有自己的檔案系統、網路和進程空間，彼此之間互不干擾。

### Dockerfile 基本指令
Dockerfile 是用來自動化建構 Docker Image 的腳本。它包含了一系列指令，每條指令都會在 Image 中建立一個層。以下是一些最常用的 Dockerfile 指令：
- **FROM**：指定基礎 Image。所有的 Dockerfile 都必須以 FROM 指令開頭，它定義了你將要構建的新 Image 所基於的起點。
- **RUN**：在 Image 構建過程中執行命令。這些命令通常用於安裝軟體包、創建目錄、編譯應用程式等。每個 RUN 指令都會在 Image 中創建一個新的層。
- **COPY**：從主機複製檔案或目錄到 Image 中。這通常用於將應用程式的原始碼或設定檔放入 Image。
- **CMD**：設定容器啟動時要執行的預設命令。如果 Docker run 命令後面沒有指定其他命令，那麼 CMD 中定義的命令將會被執行。每個 Dockerfile 中只能有一個 CMD 指令。
