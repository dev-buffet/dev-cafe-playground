## Docker 入門分享
測試講者帶來了 Docker 入門的分享，內容從容器的基本概念開始，逐步介紹了 Docker 的核心構成要素。

### 什麼是容器？
講者首先解釋了容器的定義，強調容器是一種將應用程式及其所有相依套件打包在一起的技術。這種打包方式確保了無論在任何環境中，應用程式都能夠以一致且可預期的方式執行，有效解決了傳統開發與部署中常見的環境差異問題。

### Image 與 Container
接著，分享深入探討了 Docker 中兩個核心概念：Image（映像檔）與 Container（容器）。Image 被解釋為一個唯讀的模板，其中包含了執行應用程式所需的所有環境設定、程式碼和函式庫。它是一個輕量級、獨立且可執行的軟體包。而 Container 則是 Image 的一個執行實例，可以被啟動、停止、移動和刪除，它代表了應用程式在運行時的狀態。

### Dockerfile 基本指令
在了解 Image 與 Container 之後，講者介紹了撰寫 Dockerfile 時常用的基本指令。這些指令是建構 Docker Image 的關鍵。常用的指令包括 `FROM`（指定建構基礎的映像檔）、`RUN`（在 Image 中執行指令，通常用於安裝軟體）、`COPY`（將本地檔案或目錄複製到 Image 中）以及 `CMD`（設定容器啟動時執行的預設指令）。透過這些指令，開發者可以定義如何自動化地建構出所需的應用程式執行環境。
