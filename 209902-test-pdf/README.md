## Docker 入門分享（測試講者）
測試講者帶來了 Docker 入門的分享，深入淺出地介紹了容器化的核心概念。

### 什麼是容器
講者首先解釋了容器的基礎定義，強調容器能將應用程式及其所有相依套件一同打包，確保應用在任何環境下都能一致且可靠地執行，有效解決了「在我的機器上可以動」的問題。

### Image 與 Container 的關係
接著，分享詳細闡述了 Docker 中兩個核心概念：Image（映像檔）與 Container（容器）。Image 被比喻為唯讀的模板，包含了應用程式運行所需的一切，而 Container 則是 Image 的執行實例，是應用程式實際運行的隔離環境。

### Dockerfile 基本指令
最後，講者介紹了撰寫 Dockerfile 時常用的基本指令，包括 FROM 用於指定基礎映像檔、RUN 用於執行命令安裝套件、COPY 用於複製檔案到容器內，以及 CMD 用於設定容器啟動時執行的預設命令，為聽眾建立 Docker 映像檔提供了實用的指引。
